# AGENTS.md — проектный агент-фреймворк

Это файл конфигурации для OpenCode, чтобы он понимал контекст проекта и работал максимально эффективно, экономя твои токены.

## Что это даёт

- **Сфокус на контексте**: OpenCode сразу знает структуру проекта и основные технологии.
- **Оптимизированные команды**: агент использует нужные tool-ы и avoids лишних объяснений.
- **План-подход**: сложные задачи начинаются с `/plan`, мелкие — в один шаг.

## Основные секции

### Структура проекта
- `src/` — исходники, `tests/` — тесты, `docs/` — документация.
- Основные технологии: (например, React, Node.js, Bun).
- Линтеры и форматирование: (например, ESLint, Prettier).

### Частые команды
- Построить: `npm run build`
- Запустить тесты: `pnpm test`
- Поднять dev-сервер: `npm run dev`

### Правила кода
- Используй именования CamelCase для классов, snake_case для функций.
- Всегда пиши юнит-тесты на новые функции.
- Обновляй `CHANGELOG.md` при публичных изменениях.
- Сохраняй историю коммитов: каждое изменение в отдельный коммит.

## Как использовать

Просто положи `AGENTS.md` в корень проекта. OpenCode подхватит контекст и начнёт писать код с учётом этой документации, экономя токены на уточняющих вопросах.

## Дополнительно

- При добавлении новых технологий — обновляй эту секцию.
- Уточняй задачи до начала кода: `/plan`, `/review`, `/optimize`.
- Не тащи контекст из других задач: каждая задача — новый диалог.
