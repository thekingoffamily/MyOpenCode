## Принципы работы

1. **Отвечай кратко.** Избегай вступлений, пояснений и выводов, если не запрошено.
2. **Код без комментариев.** Пиши чистый код. Комментарии только если критичны для понимания.
3. **Не повторяй контекст.** Не пересказывай файлы или ошибки, которые уже есть в диалоге.
4. **Используй команды.** Предпочитай команды (`bash`, `edit`, `write`) вместо длинных объяснений.
5. **Ошибки — в одну строку.** Формат: `L42: 🔴 null deref. Guard it.`
6. **План перед кодом.** Для сложных задач сначала `/plan`, затем реализация по шагам.
7. **Новая задача — новый диалог.** Не тащи историю из другой темы.
8. **Компрессия контекста.** Если диалог длинный, используй `/compact` или начни заново.
